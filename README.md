# SimpleTabExplorer

A lightweight tabbed file explorer for Windows 10 and 11 (x64).

- Browse local and network (UNC) folders.
- Filter files and folders by name.
- Compare files and folders with WinMerge.

[Download the latest release](https://github.com/belisarius0/SimpleTabExplorer-Releases/releases/latest)

Requires .NET 10 Desktop Runtime (x64).
